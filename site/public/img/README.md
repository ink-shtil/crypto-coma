# Site images

## Style

Black ink on cream / off-white, dense cross-hatch, starry sky — the look of
`boys_imagine_big_numbers.jpeg`. Keep any new illustration in that style so the site stays
visually of a piece with the paper's tone.

## Replacing placeholders

The `placeholders/*.svg` files are hand-made stand-ins (cream sky-gradient, ink stars,
simple silhouettes, a caption reading "placeholder"). Swap any of them for a real
illustration in the cross-hatch ink style by dropping a same-named file (or updating the
`src=` on the corresponding `<Figure>`). Suggested subjects still wanted:

- the two boys inventing `a` (a close-up, matching the hero)
- a single towering `10^10^10^…` column fading into the stars
- the crypto coma symbol `ℂ⇈` rendered as a hand-drawn glyph
